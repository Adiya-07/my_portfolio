# Adiya R — Expedition Portfolio

A cinematic, scroll-driven portfolio that connects three Himalayan expedition stages to selected AI and software projects: AstroGuy, NEXUS and Fable. The site also provides a compact project overview for visitors who prefer a conventional portfolio.

## Run locally

```sh
pnpm install
pnpm dev
```

Open http://localhost:3000.

## Production

```sh
pnpm build
pnpm start
```

Built with Next.js, React, TypeScript, Tailwind CSS, Three.js, React Three Fiber and Lenis. Photography credits are included in the portfolio.
